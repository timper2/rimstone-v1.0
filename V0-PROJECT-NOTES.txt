SEO / GEO SETUP (already built, keep it working)
- Every page is prerendered to real HTML at build time so search engines and
  AI search engines can read it without running JavaScript.
- Build command (package.json):
    vite build && vite build --ssr src/entry-server.tsx --outDir dist-server
    && node scripts/prerender.mjs && node scripts/indexnow.mjs
- scripts/prerender.mjs renders each route to dist/[path]/index.html and
  generates sitemap.xml from the route list. It stops the build with an error
  if a page is missing from vercel.json.
- public/llms.txt: plain-text summary of the site for AI search engines.
- public/robots.txt: allows all crawlers, including AI crawlers, and points to
  the sitemap.
- index.html: JSON-LD structured data (organization, courses).
- Homepage has a crawlable FAQ section (src/data/faq.ts,
  src/components/FaqSection.tsx). The FAQPage JSON-LD is rendered by
  FaqSection.tsx (home page only), not index.html.
- The committed dist/ folder: if a test build changes it, restore it with git
  before committing.
- index.html also has the Bing verification tag:
  <meta name="msvalidate.01" content="5B11AF037910DE77107EF1E047F6B9D3" />
  Do not remove it. index.html is the prerender template, so it applies to
  every page.

INDEXNOW (Bing, Yandex and others; Google does NOT use IndexNow)
- Key file: public/33c376b633b6e9e20289f68f316e599f.txt (contains the key).

WHEN ADDING A NEW PAGE
Read and follow ADDING-A-PAGE.md in the repo root, and confirm every item:
 1. src/lib/routes.ts  - add to RouteId and ROUTES
 2. vercel.json        - add the path (build fails if missing)
 3. src/pages/[Name].tsx - create the page
 4. src/App.tsx        - add a case for the route
 5. src/lib/pageMeta.ts - unique title (<60 chars) and description (<160 chars)
 6. public/llms.txt    - add page URL + one-sentence summary
 7. index.html JSON-LD - update only for a new course or service
 8. Navigation         - navbar and/or footer link if needed
 9. Images             - descriptive alt text, width and height on every <img>
10. Verify             - run the build, check dist/[path]/index.html has the
                         title, description, and content
After publishing: resubmit https://rimstonediving.com/sitemap.xml in Google Search Console
and use URL Inspection > Request indexing for the new page. Bing is notified
automatically by IndexNow on publish.
